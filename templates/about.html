CITYCARE HOSPITAL · ACADEMIC PROJECT

Intelligent FAQ answering with explainable logic.

CityCare is an offline, deterministic hospital-information prototype. It is not a diagnosis, treatment, or emergency service.

Architecture

  1. The query processor maps supported natural-language questions to a logical query.
  2. pyDatalog evaluates that query against JSON facts and FOL rules.
  3. The reasoning trace verifies and presents the actual supporting facts and derivations.

Safety and scope

  • No LLM, generative AI, external API, or invented hospital data.
  • Medical-advice questions are refused.
  • Unknown facts remain unknown rather than being guessed.
  • Admin writes validate before atomically updating the JSON file.
